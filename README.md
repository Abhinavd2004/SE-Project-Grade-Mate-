# 🎓 Grade Mate

Grade Mate is a web-based assessment platform that enables students to take **Multiple Choice Question (MCQ)** tests and **Subjective Answer** assessments in one place. The platform provides an interactive environment for learning, self-evaluation, and academic assessment by automatically evaluating objective questions while allowing descriptive responses for manual or AI-assisted review.

---

## 🚀 Features

- 📝 Take Multiple Choice Question (MCQ) quizzes
- 📖 Answer subjective/descriptive questions
- ⚡ Instant evaluation of MCQ answers
- 📊 View test scores and performance
- 📚 Support for multiple subjects and topics
- 💾 Secure storage of questions and student responses
- 🎯 Clean and intuitive user interface
- 📱 Responsive design for desktop and mobile devices

## 📖 How It Works

1. Select a subject or test.
2. Answer both MCQ and subjective questions.
3. Submit the test.
4. MCQ responses are evaluated automatically.
5. Subjective responses are stored for review or AI/manual evaluation.
6. View your results and performance summary.
